# 🎮 Survival Adventure Game

Un juego de aventura y supervivencia para móvil creado con JavaScript vanilla. Interactúa con el ambiente, recolecta recursos y sobrevive en la naturaleza.

## 🌟 Características

### Gráficos Realistas
- **Jugador personalizado** con animación fluida de movimiento
- **Ambiente dinámico** con árboles, rocas, agua y animales
- **Ciclo día-noche** con cambios graduales de iluminación
- **Partículas visuales** para efectos de recolección
- **Sombras y profundidad** para mayor realismo

### Física Realista
- **Gravedad** aplica en tiempo real
- **Fricción** en los movimientos del jugador
- **Viento** que afecta el movimiento
- **Colisiones** con objetos del ambiente
- **Animación de piernas y brazos** al caminar/correr

### Mecánicas de Supervivencia
- **Sistema de estadísticas**: Salud, Hambre, Energía
- **Recolección de recursos**: Madera, Piedra
- **Pesca** en el río
- **Caza** de animales (Ciervos y Lobos)
- **Crafting** de herramientas
- **Descanso** para recuperar energía

### Controles

**Teclado:**
- `A` o `Flecha Izquierda` - Mover izquierda
- `D` o `Flecha Derecha` - Mover derecha
- `Espacio` - Saltar
- `E` - Interactuar con objeto cercano

**Móvil:**
- Toca el lado izquierdo de la pantalla - Mover izquierda
- Toca el lado derecho de la pantalla - Mover derecha
- Usa los botones en la parte inferior

## 🕹️ Botones de Acción

- **🌲 Recolectar** - Recolecta madera de árboles cercanos
- **🎣 Pescar** - Pesca en el río
- **🔨 Crafting** - Crea herramientas con recursos
- **😴 Descansar** - Recupera energía
- **🏹 Cazar** - Caza animales cercanos

## 📊 Sistema de Estadísticas

- **❤️ Salud (0-100%)**: Decrece si tienes hambre o estás muy cansado
- **🍖 Hambre (0-100%)**: Decrece con el tiempo, especialmente si corres
- **⚡ Energía (0-100%)**: Se consume al correr y trabajar, se recupera descansando

## 🎯 Objetivos

1. **Supervivencia** - Mantén tus estadísticas en niveles saludables
2. **Recolección** - Adquiere recursos del ambiente
3. **Exploración** - Descubre nuevas áreas y objetos
4. **Adaptación** - Ajusta tu estrategia según el ciclo día-noche

## 🔧 Tecnologías

- JavaScript vanilla (sin frameworks)
- Canvas API para gráficos
- Sistema de física personalizado
- Responsive design para móvil y escritorio

## 📱 Compatibilidad

- ✅ Desktop (Chrome, Firefox, Safari, Edge)
- ✅ Tablet
- ✅ Móvil (iOS y Android)

## 🚀 Cómo Jugar

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡A sobrevivir!
